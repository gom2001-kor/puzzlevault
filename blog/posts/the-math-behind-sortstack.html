SortStack Puzzle Generation and Move Limits

March 29, 2026 · 6 min read · Updated September 26, 2026

In SortStack, a useful move does more than put two matching colors together. It can uncover a buried block, release an empty tube or finish a stack that creates extra workspace. Understanding how the starting board is built helps explain why these choices matter. It also separates two different questions: whether a route back to a sorted arrangement exists, and whether a player can find a short enough route for the selected move limit.

1. Start with the rules a move must obey

Each tube holds up to four blocks. A normal move takes one block from the top of a source tube and places it in an empty tube or on a matching top color, provided there is room. Blocks below the top cannot move directly. A tube containing four blocks of one color is complete. In the current game, completing a tube locks it and adds another empty tube to the workspace.

This makes empty capacity a resource. Two arrangements with the same colors can offer very different options depending on which blocks are exposed. Before moving, look at both the destination and the block that will become visible in the source. A matching destination is useful, but uncovering a needed color can be the more important consequence.

2. The generator works outward from a sorted board

The generator begins with four blocks of each color together, plus empty tubes. It then performs a series of reverse moves. A source is eligible when it contains only one block, or when the block immediately below its top has the same color. The destination needs spare capacity, but its top color does not have to match during generation.

That source condition is the key. Imagine reversing one generated move immediately: the moved block can return either to an empty source or to the matching color left underneath it. Reversing the recorded construction order would therefore respect the basic top-color rule. The current implementation attempts a number of mixing moves proportional to the number of colors; it does not simply distribute every block independently.

3. A construction route is not a shortest-route certificate

The game does not run a shortest-path solver after generating the board. It also does not check that a solution fits the selected move allowance. Medium, Hard and Expert currently use limits of 50, 40 and 35 moves respectively, while Easy has no move cap. Relaxed mode removes the move limit for the selected difficulty. These settings add a separate challenge to the underlying arrangement.

For that reason, the reverse-move design should not be read as a promise that every limited round can be completed within its allowance. Mixing length is not a measure of minimum solution length either: a construction may revisit earlier states or include moves that cancel each other. The algorithm explains how a return route is designed under the basic rules, rather than proving an optimal difficulty rating.

4. Spend workspace deliberately

Keep an empty tube available when possible, and ask what it will unlock before filling it. Consolidating a color can reveal a new top block, but splitting a color across several destinations may make later access harder. Look for a short sequence: expose a color, place it with its matches, then use the released capacity for another obstructing block.

Completed stacks provide additional empty tubes, so finishing one can improve later options. Still, inspect the whole board before committing several moves to a single color. A different stack may offer an earlier completion or reveal the color you need. Undo is useful for inspecting an alternative while a round remains active; it restores a move in capped modes.

5. Practice the decisions, then compare routes

Use Relaxed mode to explore a difficult arrangement without a move countdown. Describe why each move helps: it exposes a block, groups matching colors, opens a tube or completes a stack. If a move achieves none of those, reconsider it. When you return to a limited mode, focus on reducing unnecessary transfers rather than expecting one universal recipe to solve every board.

The current generator and move checks are the basis for this explanation. Try a round and pay attention to the block underneath the one you intend to move: that small observation often changes which destination is most useful.

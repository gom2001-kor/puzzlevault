TileTurn 攻略：先看十字范围，再算连锁变化

比较中心一步完成与角落误选的结果，弄清 Cascade 的对角变化及重叠抵消、Spectrum 的三种状态和星级目标。

TileTurn里，暗着的格子不一定就是应该点击的格子。每次操作会改变一组格子，因此要问的是：哪一整组需要改变？先检查候选位置周围的十字，再计算当前模式的附加效果。下列棋盘是为了讲解而构造的例子，并非实际Daily截图，也不保证是某个编号关卡的解答。

可以从TileTurn的Starter关卡包开始练习较小的Classic棋盘。总共有7个关卡包、140关；所有关卡包均可选择，但每个包内部需要按顺序解锁。既可直接点击，也可通过正常键盘焦点操作选中并激活格子按钮。

三种模式的第一步都是十字

一次点击的作用
模式变化目标
Classic翻转所选格及上下左右邻格的亮暗全部点亮 ●
Cascade先翻转十字，再由新亮起的格子翻转其邻格全部点亮 ●
Spectrum十字范围按 ○ → ◆ → ✓ → ○推进全部绿色 ✓

上下左右不包含对角线。在3×3棋盘中，中心的第一步影响5格，非角落边缘影响4格，角落影响3格。超出边界的效果不会从另一边绕回来。

Classic：只需一步的例子

A到C表示从上往下的行，1到3表示从左往右的列。●是亮，○是暗。先列出暗格：A2、B1、B2、B3、C2。这五格刚好就是以B2为中心的十字。

  1. 虽然有多个暗格，先把B2作为候选。
  2. 检查完整影响范围：B2、A2、C2、B1、B3。
  3. 这些格子全部是暗的，翻转后全部变亮。
  4. 原本点亮的四个角不在十字里，因此保持不变。

看起来也不错的错误选择是A1，因为它能接触两个暗格。它会点亮A2和B1，却同时让A1变暗，B2、B3和C2也仍然是暗的。亮格数量从4增至5，但没有完成棋盘。适合本例的选择是B2，它的范围正好覆盖全部五个待改变位置。由此可见，一步后亮格更多，并不能单独证明方案更好。

Cascade为什么会改变对角格？

Cascade先进行同样的十字翻转。300毫秒后，只有第一步中从暗变亮的格子，才会翻转自己的上下左右邻格。第二步不会翻转作为发射点的格子自身，也不会因新亮起的格子而无限继续传播。

另构造一张4×4棋盘，只有B1暗着，其余全亮。点击B2后，第一步只有B1新变亮；B2、A2、B3、C2则变暗。随后B1把第二步效果发到A1、C1、B2。A1和C1变暗，B2重新变亮。从最初点击的B2看，A1和C1位于对角方向，但它们是经过B1才改变的。游戏并不存在独立的“直接翻转对角线”模式。

还要考虑重叠。如果点击B2前，A2和B1原本都暗，那么两者都会成为第二步的发射点。A1分别收到一次翻转，总共两次，最终保持原来的状态。操作前列出第一步新变亮的位置，再数共享邻格会收到几次影响。预览强调的是涉及范围，不表示每个高亮格的最终状态一定会不同。

Spectrum要计算三种状态

Spectrum的循环是暗色○ → 蓝色◆ → 绿色✓ → 暗色○。蓝格再推进一次就变绿，暗格需要两次，原本绿色的格子若在十字里则会变暗。只盯着被点击的一格，会忽略同时改变的邻格。

Classic中，同一位置按两次，棋盘变化会相互抵消；Spectrum中需要按三次。不要把这个规则直接套用到Cascade，因为连锁发射点取决于当时的棋盘状态。

用撤销比较方案，正确理解目标步数

比较两种候选操作时，可免费使用Undo回到上一张棋盘。反复点击同一格来“恢复”会增加步数，在Cascade中还可能无法回到原状态。连锁模式要等两步动画结束后，再判断完整结果。

显示的目标步数来自棋盘构造过程，并不代表数学上证明的最少步数。用不超过目标的步数完成可得三星，超过目标最多两步可得两星，其余完成则得一星。分数也奖励效率；没有使用提示时，在加入关卡包完成奖励之前还会增加20%。这些是游戏的计分目标，并不能证明不存在更短解法。

最后检查影响范围

在第一张3×3 Classic示例里，点击B2会改变A1吗？Spectrum里最初为暗色的格子要推进几次才能变绿？

查看答案

不会，A1在B2的对角方向，不属于Classic的十字范围。Spectrum暗格需要两次：○ → ◆ → ✓。这里回答的是单个格子的变化；要解完整棋盘，仍必须计算每次点击共同影响的邻格。

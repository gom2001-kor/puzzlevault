# 영어 학습실 통합 — 2026-09-28

사용자 소유 `study-english2.pages.dev`의 Little by Little Reading Room을 PuzzleVault의 `/learn/english/` 경로에 통합했다. 기존 영어 앱의 로컬 원본 저장소는 수정하지 않았다. 5개 언어 홈과 공통 메뉴·푸터에서 들어갈 수 있으며, 학습 앱의 인터페이스와 해설은 한국어다.

## 포함한 학습 기능

영어 원문 8편, 선정 학습 구간 69개와 기존 원문·번역·구문·문법·문맥 단어 풀이를 보존했다. 끊어 읽기, 기기 합성 음성, 받아쓰기, 최대 60초 로컬 녹음, 글쓰기, 복습장과 복습 일정, 기존 v2 JSON 백업을 사용할 수 있다. 본문 미확인 자료 2편은 학습 및 탐험에서 제외한다. 자료별 저자·출처·이용 조건과 소프트웨어 라이선스 고지도 유지한다.

## 새 영어 탐험

- 단어 뜻 고르기, 의미 덩어리로 문장 조립하기, 원문을 읽고 내용 확인하기를 두 번씩 만나는 6문제 코스.
- UTC 날짜에 따라 정해지는 오늘의 탐험과 수업별 연습.
- 제출 후 정답과 해설, 오답 다시 풀기, 복습장 저장과 원문 수업 연결.
- 중간 답안과 진행 저장. 일일 최초 완료에 30 XP와 정답당 10 XP를 지급하며 같은 날짜에는 중복 적립하지 않는다.
- 기존 12개 게임 XP와 영어 학습 XP를 분리한다. 탐험을 풀었다고 원문 수업을 완료한 것으로 처리하지 않는다.
- 저장 오류가 생기면 손상된 원본 값을 보존한다. 같은 앱 안에서 수업을 오가도 임시 탐험 진도를 유지하지만 새로고침하거나 탭을 닫으면 임시 진도는 사라진다.

## 화면과 사용성

PuzzleVault 브랜딩과 언제든 게임으로 돌아가는 링크를 추가했다. 외부 Google Fonts 호출을 제거하고, 모바일 메뉴의 키보드 포커스·Escape·본문 전환을 보완했다. 작은 화면과 200% 글자 확대에서 수업 내용이 가로로 넘치던 문제를 수정했다. JavaScript가 꺼져 있어도 학습 방법·자료 범위·출처·기록 이전 안내는 읽을 수 있다.

## 기존 기록 이전

1. 기존 영어 앱의 설정에서 **전체 기록 백업**을 받는다.
2. PuzzleVault 영어 학습실의 설정에서 JSON 파일을 선택한다.
3. 복원 미리보기를 확인한 뒤 **이 백업으로 복원**을 누른다.

주소가 다른 두 사이트의 기록은 자동으로 공유되지 않는다. 기존 카드 ID·자료 순서·v2 백업 형식을 유지했으며, 통합판의 읽기 저장 키는 `pv_english_reading_v2`, 탐험은 `pv_english_quest_v1`이다. 녹음과 새 탐험 기록은 기존 읽기 백업에 포함되지 않는다.

## 검증

- PuzzleVault Node 테스트 155개, 영어 앱 테스트 76개 통과: 합계 **231개**.
- 기존 학습 UI 18항목, 구문·단어·조립·음성 제어 16항목 통과.
- 추가 통합 브라우저 검사에서 6문제 완주, 결과 재진입, 오답 복습, 일일 XP 중복 방지, 기존 게임 및 읽기 기록 보존, 손상 저장 상태의 수업 왕복을 확인했다.
- 5개 언어 홈과 개인정보 페이지, 320–1440px 화면, 키보드 메뉴 및 200% 읽기 화면 확대를 확인했다.
- 버전 18 서비스 워커가 해시 번들 전부를 저장하며, 오프라인에서 영어 읽기·탐험·기존 퍼즐이 실행된다.
- 공개 HTML 123개, 기존 게임 12개 정적 검사: 차단 항목·경고 0개. 기존 글의 보장을 부정하는 문장 3개는 키워드 검사의 수동 검토 대상으로 남아 있다.

테스트 브라우저에서 실행 오류와 자동 외부 요청은 없었다. 실제 영어 음질과 마이크 장치 녹음은 검증하지 않았으며 합성 음성의 순서·취소 테스트는 통제된 이벤트로 수행했다. 기기 음성에 따라 네트워크가 필요할 수 있다.

## 유지보수와 배포

소스는 `apps/english/`, 빌드 결과는 `learn/english/`에 보관한다. 빌드 시 서비스 워커의 파일 목록도 자동 갱신한다. React 실행 코드·읽기 자료·상세 해설·앱 코드를 별도 번들로 나눠 큰 단일 파일을 줄였다. 기존 PuzzleVault 본체는 정적 HTML/JavaScript 구조를 유지한다.

재현 방법은 [모듈 README](../apps/english/README.md)에 있다. `python scripts/package-site.py`는 소스·의존성·내부 문서를 제외한 정적 배포 ZIP을 만든다. ZIP에는 Cloudflare Functions가 포함되지 않으므로 CLI 배포에서 기존 `functions/` 미들웨어를 사용할 때는 저장소에서 함께 배포한다. Git 커밋·푸시는 실제 Cloudflare 공개 배포와 별도다.

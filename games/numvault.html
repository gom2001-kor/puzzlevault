How to Play NumVault

Crack a hidden code of 4–6 digits using the feedback after each guess. Green means the correct digit in the correct position; yellow means a matching digit belongs elsewhere. Gray means this copy of the digit has no unmatched place in the code. Exact matches are assigned first, which matters when digits repeat. The Number Tracker summarizes clues for digits 0–9, while the guess rows preserve position information. Easy uses four different digits; higher difficulties allow repeats. Daily offers one recorded attempt on the shared UTC puzzle, then Free Play remains available. Speed starts with 60 seconds and adds 15 seconds for each solved code. Try broad guesses first, then use the clues to narrow positions. Hints reveal one position: up to one in Daily or two in Free Play, with none in Speed.

Frequently Asked Questions

What is the Number Tracker?

It summarizes the clues for digits 0–9 below the grid. Check the guess rows for each position and repeated-digit counts.

How does the feedback work?

Green matches are assigned first, then yellow matches use remaining copies of each digit. Gray means no unmatched copy remains, so it does not always rule out that digit entirely.

Can digits repeat?

Easy uses distinct digits. Normal, Hard, and Expert allow repeated digits.

When does Daily reset?

At midnight UTC. Everyone gets the same code. After your daily attempt is recorded, use Free Play until the next puzzle.

How do hints work?

A hint reveals one unconfirmed position. Daily allows one, Free Play two, and Speed none. Using one removes the no-hint score bonus and is noted in the shared result. Help is currently free; a configured reward ad would ask first.

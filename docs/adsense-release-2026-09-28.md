# AdSense 준비 보완과 영어 콘텐츠 자동 연동

2026-09-28, PuzzleVault 운영 사이트와 원본 영어 사이트를 함께 보완했다. AdSense의 기존 화면에서 확인된 사유는 ‘가치가 별로 없는 콘텐츠’였다. 이번 작업은 콘텐츠의 실제 학습 가치·접근성·정확한 서비스 안내·광고 요청 조건을 개선한 것이며, Google 계정의 승인 판정이나 재검토 신청을 대신하지 않는다.

## 보완한 내용

- 영어 자료 8편의 선정 문장·한국어 풀이·끊어 읽기·문법 예문·확인 질문·출처를 JavaScript 없이 읽을 수 있는 가이드 9페이지로 제공했다. 새 자료가 추가되면 같은 검증 데이터에서 다시 생성한다.
- 5개 언어의 소개·문의·개인정보·약관과 편집정책을 영어 학습실의 실제 기능에 맞췄다. 원문과 자체 해설, 개별 이용 범위, 수정·권리 제보 방법을 구분했다.
- ‘의견 보내기 양식 열기’는 본문 링크 규칙 때문에 배경과 글자가 같은 색이 되던 문제를 해결했다. 밝은/어두운 모드 모두 흰 글자와 진한 파랑 배경이며 대비는 약 6.7:1이다. PuzzleVault 명칭과 기존 문의 양식은 유지했다.
- 실제 사이트에서 없는 주소를 200으로 반환하던 문제를 404 페이지로 수정했다. 개발 소스·테스트·문서는 공개 파일 묶음에서 제외했다.
- 실제 광고 요청에는 제품·현재 동의 조건을 매번 확인하도록 했다. 자동 광고 새로고침은 사용하지 않으며, 일반 AdSense와 게임용 보상형/전면 광고 제품의 자격을 구분했다. 아직 실제 광고 공급자는 활성화하지 않았다.

## 자동 연동의 동작

원본 영어 프로젝트의 `main`에 콘텐츠를 커밋·푸시하면 연결된 Cloudflare가 빌드하며 공개 JSON 피드를 함께 만든다. PuzzleVault 영어 학습실은 다음 진입 또는 새로고침에서 이 피드를 한 번 확인해 적용한다. 이미 공부하고 있는 화면을 도중에 바꾸지는 않는다.

피드는 허용된 6개 JSON 파일만 포함한다. 데이터 구조, 크기, 원문과 해설의 일치, 권리 표시, 해시, 기존 카드 ID를 검사한다. 오류·통신 실패 시 마지막 정상 자료 또는 앱에 포함된 자료로 계속 이용한다. 학습 기록·답안·녹음은 원본 사이트로 보내지 않는다.

새 수업으로 문제 은행이 달라져도 XP·최고 기록·읽기 기록은 유지한다. 이전 선택지를 새 선택지로 재해석하지 않도록 진행 중인 탐험만 안내 후 새로 시작하며, 같은 날짜 XP를 중복 지급하지 않는다. 기존 카드의 영문·인덱스나 정답을 바꾸는 업데이트는 별도 기록 이전 설계가 필요하므로 자동 반영을 중단한다.

GitHub Actions는 15분 간격으로 같은 피드를 확인한다. 변경이 있을 때만 테스트·앱 빌드·정적 가이드 생성·사이트 검사를 거쳐 커밋한다. 연결된 Cloudflare가 `python3 scripts/package-site.py --directory`를 실행해 `dist/site`를 공개하므로 정적 페이지도 후속 반영된다. 예약 작업은 GitHub 및 호스팅 대기 시간에 따라 지연될 수 있다.

## 검증 및 공개 반영

- PuzzleVault 루트 자동 테스트 175개, 영어 학습 앱 82개: **257개 통과**. 원본 영어 프로젝트의 기존 테스트 63개도 통과했다.
- 5개 언어 문의 버튼: 320/390/1280px × 밝은/어두운 모드, 30개 대비·레이아웃 검사 통과.
- 정적 영어 가이드: 18개 화면 조합에서 제목·가로 넘침 검사 통과.
- 제어된 새 자료를 실제 브라우저에 공급해 수업 추가, 최신본 적용, 오프라인 캐시, 변조 자료 차단, XP 보존을 확인했다.
- 기존 6문제 완주·오답 복습·중복 XP 방지·손상 저장 보호와 오프라인 기존 게임 실행을 다시 확인했다.
- 공개 사이트에서 원본 피드 200/JSON/CORS, 최신 원본 적용 표시, 문의 버튼의 흰 글자, 존재하지 않는 페이지와 개발 경로의 404, 실행 오류 0건 및 광고 요청 0건을 확인했다.

## 계정에서 남은 단계

AdSense 사이트 화면에서 수정 사항을 확인하고 재검토를 요청해야 한다. 승인은 Google이 결정하며 콘텐츠 분량이나 이 작업만으로 보장되지 않는다. 승인 뒤 실제 광고 단위와 대상 지역·제품에 맞는 동의/CMP를 설정하고 별도로 검증해야 한다. 이번 배포에서 실광고를 켜거나 광고를 클릭해 시험하지 않았다.

자료의 원문 및 상업적 이용 권리를 자동 검사만으로 확정할 수는 없다. 개별 원문·지역별 조건의 실제 검토와 오류 수정 책임은 운영자에게 남는다. 정책과 운영 절차는 [광고 운영 안내](adsense-operations-2026-09-28.md), [콘텐츠 연동 안내](ENGLISH_CONTENT_SYNC.md), [콘텐츠 검토](adsense-content-review-2026-09-28.md)를 참고한다.

기준: [Google의 AdSense 페이지 준비 안내](https://support.google.com/adsense/answer/7299563?hl=ko), [Google 게시자 정책](https://support.google.com/adsense/answer/10502938?hl=ko), [Cloudflare Git 자동 배포](https://developers.cloudflare.com/pages/configuration/git-integration/).

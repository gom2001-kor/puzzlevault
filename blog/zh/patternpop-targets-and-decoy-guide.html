PatternPop 攻略：记住目标位置，分清干扰闪光

用一个含六个目标的示例棋盘练习 PatternPop，了解选择顺序、红色干扰、生命、慢速重播提示及计分规则。

攻略的编写与核对方法

本文内容

  1. 把六个目标分成容易检查的小组
  2. 比较两个选择
  3. 棋盘扩大后重新建立位置基准
  4. 理解得分，避免为了快而乱猜

PatternPop 要你记住的是哪些格子是目标，而不是闪光顺序。蓝色 ◆ 目标会一起出现，消失后可以按任意顺序选择对应位置。如果试图还原一串闪烁顺序，就会额外记忆游戏并不要求的信息。

打开 PatternPop，选择模式，准备好观察后再按开始按钮。触屏可直接点格子；使用键盘时，先让棋盘获得焦点，再用方向键移动，按 Enter 或 Space 选择。观察阶段结束、进入回忆阶段后才需要作答。

把六个目标分成容易检查的小组

下面是为讲解规则构造的练习例子，并非某一天 Daily 的截图。它采用第5轮的条件：4×4棋盘、6个目标、1个干扰格。A到D表示从上往下的行，1到4表示从左往右的列。◆需要记住，×需要忽略。表格为了方便比较而同时保留两种符号，实际游戏里的干扰格只会短暂闪烁。

  1. A行是左边的一对：A1和A2。
  2. B行只有最右边的B4。不要把B2的×算进去。
  3. C行是中间的一对：C2和C3。
  4. D行只有最右边的D4。

这样就可以记成“左边两个、右边一个、中间两个、右边一个”。数量也能核对：2 + 1 + 2 + 1 = 6。并不是每张棋盘都会形成整齐的形状；在这个例子中，按行分组是为了检查遗漏和重复，而不是宣称存在万能的记忆口诀。

比较两个选择

容易出错的选择：你只记得B2闪过，于是先点B2。它不是目标，在Classic或Daily中会扣掉一条生命，六个目标仍然都要寻找，而且本轮不再满足“没有错误”的加倍条件。红色干扰格没有额外加重处罚，点其他非目标格同样会损失一条生命。

符合规则的选择：只选出现过◆的六个位置。A1 → A2 → B4 → C2 → C3 → D4能够完成，反过来按D4 → C3 → C2 → B4 → A2 → A1也一样有效。固定按行输入只是帮助自己知道已经选到哪里，并非游戏的硬性要求。重复点击已经选过的格子，不会算作又找到一个目标。

棋盘扩大后重新建立位置基准

第1至4轮是3×3，第5至8轮是4×4，第9至14轮是5×5，第15轮起是6×6。干扰格从第5轮开始出现，最多增至4个，正常闪烁持续0.3秒。除了颜色，也要认清◆与×的符号。棋盘变大时，原来的“中间位置”不一定还是新的中间，先重新划分行列，再记目标。

Classic和Daily从三条生命开始。Endless生命无限，适合在不会因几次错误而结束的情况下比较不同记忆方法。Speed只有一条生命，但目前的记忆展示时间与Classic相同。Daily使用共同的种子布局，也允许重复练习。和朋友比较成绩时，可以说明是第一次观察，还是练习同一关后得到的结果，避免把两种不同条件混在一起。

理解得分，避免为了快而乱猜

完成一轮后，基础分为目标数量×100。这个例子有6个目标，因此基础分是600。若没有错误选择，且游戏测得的每个目标平均用时小于0.5秒，该轮得分翻倍到1,200。把速度奖励看作准确回忆后的额外奖励即可；它并不意味着应该猜一个不确定的第七格。没有达到速度要求，只要正确完成，仍能得到基础分。

如果忘记部分位置，提示会把同一组目标放慢重播，已经找到的目标也会保留。它不会换成一张更简单的棋盘。可以重点看不确定的那一行，随后从剩余目标继续，而不是把选过的格子全部重选一遍。

遮住图表试一次

假设已经正确选中了A1、B4和C3，剩下的三个目标是什么？还需要选择B2吗？

查看答案与解释

剩下的是A2、C2和D4，可以按任意顺序选。B2是×干扰格，应该忽略。如果只记得“B行出现过东西”，却忘记了符号，问题在于把干扰格混进了目标集合。先练习区分两类符号，再逐渐提高输入速度。

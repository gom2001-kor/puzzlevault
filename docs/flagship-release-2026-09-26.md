# PuzzleVault 두 메인 게임 추가 — 2026-09-26

## 이번 버전의 범위

- **Mosslight Wardens / 이끼빛 수호대**: 세 숲 구역, 수정 생물과 최종 수호자, 빛의 정원 회복·강화, 파동 공격·회피, 구역 사이 능력 선택, 승리와 재도전.
- **Cloudweft Passage / 구름결 여정**: 세 챕터의 공중섬, 해·달에 따라 실체가 바뀌는 다리, 점프·순찰등·바람문, 문양과 선택 유물, 섬 체크포인트, 완결된 여정.
- 두 게임 모두 WebGL의 실제 입체 메시를 사용한다. 5개 언어 UI·조작법·FAQ, 모바일 버튼, 키보드, 소리 설정, 일시정지, 로컬 저장, 날짜를 보존하는 일일 도전 공유를 제공한다.
- 5개 언어 홈페이지의 첫 영역에 두 메인 게임을 배치했다. 기존 퍼즐 10개를 포함한 총 12개 게임이 탐색·추천·성장 시스템에 등록된다. 블로그에서 새 게임의 상세 가이드로 이동할 수 있다.
- 서비스 워커 캐시는 v16이다. 신규 렌더러·두 게임·홈페이지 자산을 사전 저장한다.

## 기획 근거와 자료의 범위

2026년 공개된 Newzoo 자료는 상위권의 슈팅·배틀로얄과 샌드박스 생태계, 그리고 상위 20위 밖의 RPG·어드벤처 이용 증가를 설명한다. 이 자료는 주로 PC·콘솔 시장 분석이며, 이 사이트의 방문 수나 웹게임 광고 수익을 예측하는 자료는 아니다.

- [Newzoo: 상위 20위 밖의 이용 시간·매출과 RPG/어드벤처](https://newzoo.com/articles/playtime-revenue-beyond-top-20)
- [Newzoo: 2026 PC·콘솔 시장 분석](https://newzoo.com/articles/post-pandemic-growth-pc-console)

이 프로젝트에서는 설치 없이 시작할 수 있고, 짧은 탐험 안에 성장 선택·공간 퍼즐·발견을 담을 수 있는 두 장르를 선택했다. 이용자 반응과 난이도는 실제 공개 후 완료율·재방문·피드백으로 조정할 필요가 있다.

## 새 자산의 출처

- `js/pv3d.js`: 이 저장소에서 작성한 WebGL 렌더러. 상자·원뿔·팔면체·기둥·평면의 정점, 법선, 셰이더를 코드로 생성한다. 외부 엔진 패키지가 없다.
- 게임의 캐릭터·적·식물·섬·다리·봉화: 직접 작성한 도형 조합과 좌표 배치. 외부 게임의 모델·텍스처·스크린샷을 내려받지 않았다.
- 홈페이지 표지: 직접 작성한 SVG 도형과 CSS. 기존 작품의 캐릭터나 로고를 사용하지 않았다.
- 효과음: 기존 프로젝트의 `js/sfx.js` Web Audio 오실레이터. 외부 음원 파일을 추가하지 않았다.
- 게임 이름은 기존 유명 게임을 모방하지 않도록 정했으며, 공개 이름 검색도 수행했다. 이는 전 세계 상표 등록 조사나 법적 비침해 보증을 뜻하지 않는다.

## 광고 및 배포 상태

`AdController`의 공급자는 계속 비활성 상태다. 두 게임은 실제로 끝난 결과에서만 광고 기회를 호출하고, 광고 API 대기 중 재시작을 잠근다. 기본 플레이·회복·재도전·챕터 완료에는 광고 시청이 필요하지 않다. 현재 페이지에 실광고를 요청하는 기본 경로는 없다.

Google 계정 승인이나 실서비스 광고 설정은 이번 게임 구현과 별개다. [광고 연결 준비 문서](monetization-readiness.md)를 따른다. 이번 변경만으로 AdSense 승인, 바이럴 확산 또는 수익이 검증된 것은 아니다.

이 변경은 소스 코드와 로컬 미리보기의 구현·검증이다. Cloudflare Pages Direct Upload 배포와 AdSense 재검토 요청은 실행하지 않았다.

## 검증 기록

전체 Node 테스트 137개를 통과했다. 정적 점검은 공개 HTML 122개·게임 12개에서 차단 오류 0개, 경고 0개다. 자동 문구 점검의 검토 항목 3개는 기존 공략에서 보장하지 않는다고 설명한 문장의 일치이며, 수동 검토했다.

- 게임 규칙: `tests/mosslight.test.js`, `tests/cloudweft.test.js`.
- 3D 메시·카메라 수학: `tests/pv3d.test.js`.
- 전체 게임 등록·로컬 언어·사전 캐시: `tests/arcade-integration.test.js`.
- 브라우저 점검 결과: `flagship-browser-checks.json`.
- 정적 사이트 점검 결과: `site-audit-results.json`.

브라우저 점검은 Windows Microsoft Edge의 Chromium/WebGL에서 수행했다. 모바일 항목은 화면 크기와 입력 동작의 브라우저 점검이며 모든 실기기·GPU의 성능을 보장하지 않는다. WebGL을 사용할 수 없을 때는 게임을 시작시키지 않고 안내와 기존 퍼즐 링크를 유지한다.

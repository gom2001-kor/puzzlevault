# PuzzleVault 게임 업그레이드 및 AdSense 준비 점검

후속 확인: 이후 제공된 AdSense 화면에서 **가치가 별로 없는 콘텐츠**라는 사유를 확인했습니다. 아래 내용은 첫 점검 당시의 기록이며, 이후 콘텐츠 개선과 최신 검증 결과는 [콘텐츠 개선 기록](editorial-upgrade-2026-09-26.md)에 정리했습니다.

점검일: 2026-09-26. 범위: 저장소의 공개 HTML 85개, 게임 10종, 5개 언어, 브라우저 로컬 실행과 공식 Google 문서. 사용자는 거절 통지나 메일을 받지 않았다고 확인했습니다. 따라서 아래 사항은 확인된 거절 사유가 아닌, 소스에서 발견한 개선 사항입니다. AdSense 계정 상태, 심사 결과, 운영 사이트의 배포 상태는 이 점검으로 확인되지 않습니다.

## 게임 경험

평면 규칙이 명확한 퍼즐에 무거운 3D 엔진을 추가하는 대신 Canvas/CSS의 음영·두께·재질·충돌 표현으로 10종 모두 입체감을 높였습니다. 자유 시점이나 3D 공간 물리가 있는 게임으로 바뀐 것은 아닙니다. 설치, 외부 모델 다운로드, 빌드 도구는 필요하지 않습니다.

| 게임 | 적용한 변화 |
| --- | --- |
| NumVault | 금고 패널, 입체 숫자 키, 확정된 자리 진행 표시, 색과 기호 피드백 |
| GridSmash | 두께 있는 블록과 홈, 배치 전 완성 라인 표시, 회전 가능한 수를 고려한 종료 판정, 키보드 배치 |
| PatternPop | 입체 기억 패드, 명시적인 준비 버튼, 진짜/방해 패턴의 ◆/× 구분, 키보드 입력 |
| SortStack | 유리 튜브와 번호 구슬, 옮길 수 있는 튜브 표시, 모바일 내부 가로 스크롤 |
| QuickCalc | 입체 답안 키, 연속 정답 목표, 타이머 강조; 같은 문제의 30초 친구 대결 유지 |
| TileTurn | 두께 있는 타일과 상태 기호, 영향 범위 미리보기, 남은 목표와 키보드 조작 |
| ColorFlow | 번호 보석, 두께 있는 연결 경로, 남은 쌍과 빈칸 표시 |
| PipeLink | 금속 회로와 접점, 흐르는 전력 표시, 모양과 글자로 구분한 단자 |
| MergeChain | 광택 구슬, 충돌 눌림, 용기 깊이, 첫 충돌 위치 조준 안내와 키보드 낙하 |
| HexMatch | 면이 나뉜 보석, 색 외에 모양 구분, 순서가 표시되는 연결 힌트와 점수 예고 |

시각 효과는 무작위 문제 생성값이나 점수를 바꾸지 않도록 분리했습니다. 움직임 줄이기 환경에서는 장식 효과를 줄입니다. 기존 일일 미션·XP·배지·저장 가능한 공유 카드와 친구 도전 링크를 유지합니다. 실제 바이럴 확산과 재방문 상승은 배포 후 관측할 결과이며 보장하지 않습니다.

## 발견 사항과 처리

| 발견한 문제 | 변경 내용 | 남는 확인 사항 |
| --- | --- | --- |
| 동의 전 AdSense·GA·Clarity 태그가 실행되고 개인정보 문구는 외부 전송이 없다고 설명 | 자동 광고·Clarity 로드 제거. GA는 명시적 허용 이후 다음 운영 페이지에서만 실행. 하단 설정에서 철회 가능 | 운영 도메인이 바뀌면 분석 허용 호스트 변경. 기존 전송 데이터의 삭제나 계정 보유기간 변경은 별도 |
| 광고가 연결되지 않은 힌트에도 광고를 약속하는 표시 | 잘못된 표시 제거, 기본 도움은 무료. 실제 provider가 있을 때만 명시적 보상 광고 동의·완료 콜백 사용 | 광고 제품 자격 및 실 SDK 연결·검증 |
| 설명과 실제 규칙 불일치 | 가이드·FAQ를 실제 점수/조작/목표에 맞게 정리하고 5개 언어 수정 | 미래 규칙 변경 때 설명도 함께 갱신 |
| 의학적 효과, 60fps 보장, 최적/100% 풀이 등의 근거 없는 주장 | 플레이 방법과 실제 구현을 설명하는 원고로 교정. 미검증 성능·능력 향상 약속 제거 | 운영자 명의와 공개 연락처는 실제 정보만 보완 |
| 공통 메뉴와 게임 목록이 JS 실행에 의존 | 모든 공개 페이지에 정적 메뉴·정책 링크, 홈에 실제 게임 링크 제공 | 운영 서버의 정상 응답 및 크롤러 접근 확인 |
| 소개·개인정보·약관·문의가 실제 서비스와 불일치 | 5개 언어의 20개 지원 페이지를 재작성. 기존 문의 폼은 명시적 외부 링크로 제공 | 폼 소유자가 응답 수신과 문의 처리 확인 |
| 오래된 캐시가 이전 게임 코드를 유지 | 변경 자산 버전과 서비스 워커 캐시 갱신, 새 그래픽/개인정보 자산 포함 | 기존 방문자는 업데이트 후 한 번 새로고침 필요할 수 있음 |
| 검색용 구조 데이터에 존재하지 않는 검색 기능 | 사용하지 않는 SearchAction 삭제, 메타와 canonical/내부 링크 점검 | 검색 노출 및 심사 통과는 별도 결과 |

## 정책 판단 근거

- Google은 독창적이고 이용자에게 유용한 콘텐츠, 읽기 쉽고 동작하는 내비게이션, 좋은 이용 경험을 강조합니다. 게임별 실제 규칙과 도움말을 보강한 이유입니다. 이 문서는 특정 글 수·단어 수·방문자 수를 승인 보장 조건으로 제시하지 않습니다. [페이지 준비 기준](https://support.google.com/adsense/answer/7299563?hl=en)
- 콘텐츠가 없거나 가치가 낮은 화면, 오해를 유도하는 광고 배치, 개인정보 고지 문제를 함께 고려해야 합니다. 형식적인 정책 페이지의 존재만으로 정책 준수가 완성되지는 않습니다. [Google 게시자 정책](https://support.google.com/adsense/answer/10502938?hl=en)
- 게임 조작과 광고의 우발적 클릭을 피해야 합니다. Google은 콘텐츠 광고를 게임에서 150px 이상 떨어뜨리거나 게임 페이지에서 제거할 것을 **강하게 권장**합니다. 이를 모든 광고 형식에 대한 일률적인 의무 수치라고 해석하지 않았습니다. 현재는 자동 광고를 요청하지 않습니다. [게임 페이지 광고 안내](https://support.google.com/adsense/answer/2768340?hl=en)
- EEA·영국·스위스의 광고 제공에는 Google 인증 및 TCF 통합 CMP 요구사항을 확인해야 합니다. 이번 하단 설정은 선택형 Analytics 제어이며 인증 광고 CMP가 아닙니다. [Google 동의 관리 요구사항](https://support.google.com/adsense/answer/13554020?hl=en)
- 소유권은 광고 코드 외에도 메타 태그 또는 ads.txt로 확인될 수 있습니다. 기존 게시자 ID를 두 곳에서 유지하고 일치 여부를 검사합니다. 광고 제공은 사이트 심사를 통과한 계정의 **Ready** 상태에서 가능합니다. [AdSense 사이트 관리](https://support.google.com/adsense/answer/12131223?hl=en)

## 로컬 검증

`node --test tests/*.test.js`로 게임 종료 중복, 공유 링크의 동일 문제, 잘못된 입력, 모바일 좌표 매핑, 색 외 상태 구분, 광고 콜백과 개인정보 선택을 검증합니다. `python scripts/audit-site.py`는 공개 페이지의 메타, 로컬 링크, 정적 메뉴, 중복 ID, 직접 추적 태그, 게시자 ID를 확인하고 문제가 있으면 실패 코드로 종료합니다. 검사 결과 JSON은 `docs/site-audit-results.json`에 저장합니다. 이 검사는 정책 전체의 자동 판정기가 아닙니다.

390px 모바일 화면에서 10개 게임 렌더링과 대표 조작을 수동 확인했습니다. 블록 키보드 배치, 튜브 이동, 타일 완료, 보석 연결, 회로 회전, 기억 패드 정답과 암산 정답 처리를 확인했습니다. 모든 기기·모든 레벨·실광고 SDK의 검증을 뜻하지 않습니다.

최종 자동 테스트는 **87개 통과**했습니다. 공개 HTML 85개의 구조 검사는 차단 항목 0개, 경고 0개입니다. 문구 검사에 남은 1개 표시는 한국어 NumVault 글의 "보장하지는 않습니다"를 보장 표현으로 찾은 오탐이며 원문을 직접 검토했습니다. 실제 문의 폼의 제목과 입력 항목이 열리는 것까지 확인했고, 메시지를 제출하지는 않았습니다. 320px 및 390px 화면에서도 상단 조작이 페이지 밖으로 밀리지 않도록 점검했습니다.

## 계정과 배포에서 남은 일

1. 변경본을 운영 사이트에 배포하고, 홈·정책·게임·ads.txt가 공개 URL에서 응답하는지 확인합니다. 이번 작업은 로컬 변경이며 배포나 심사 신청은 수행하지 않았습니다.
2. AdSense → 사이트에서 정확한 등록 도메인과 현재 상태를 확인합니다. 메일이 없다는 사실만으로 거절 또는 승인으로 판단하지 않습니다. 계정에서 요구하는 소유권 확인과 검토 요청이 남아 있으면 완료합니다.
3. 운영자 공개 정보와 문의 수신 경로를 확인합니다. 제공되지 않은 사람 이름이나 이메일은 임의로 만들지 않았습니다.
4. 광고를 활성화할 때 인증 CMP 및 대상 지역 설정, 게임 조작과 떨어진 배치, 공급자 테스트 모드의 완료/취소/광고 없음 흐름을 검증합니다. 자체 실광고 클릭으로 시험하지 않습니다. 세부 연결 계약은 `monetization-readiness.md`를 따릅니다.
5. 실제 첫 판 완료율·재방문·도전 링크 유입을 관측하고 이후 유효 노출과 수익을 비교합니다. UI 개선이나 광고 ID만으로 승인·바이럴·수익을 보장하지 않습니다.

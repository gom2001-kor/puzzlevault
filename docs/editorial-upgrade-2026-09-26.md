# PuzzleVault 콘텐츠 개선 기록

작업일: 2026-09-26. 사용자가 제공한 AdSense 화면에서 사이트 소유권 확인은 초록색, 사이트 심사 사유는 **가치가 별로 없는 콘텐츠**로 표시되어 있음을 확인한 뒤 수행한 개선입니다. 화면은 문제 URL, AI 판정, 최소 글 수나 방문자 수를 제시하지 않습니다. 아래 검사는 콘텐츠·기술 개선의 증거이며 Google의 승인 판정이 아닙니다.

## 적용 결과

- 독립 주제 9개 → 15개. 5개 언어를 합친 게시물 45개 → 75개. 번역을 서로 다른 주제로 세지 않습니다.
- NumVault, GridSmash, SortStack, ColorFlow 기존 공략을 실제 규칙·계산·풀이 중심으로 다시 작성했습니다.
- PatternPop, QuickCalc, TileTurn, PipeLink, MergeChain, HexMatch 전용 공략을 새로 작성했습니다.
- 10개 공략마다 설명용 표 또는 SVG 게임판, 선택 비교, 단계별 풀이, 직접 풀어볼 과제를 제공합니다. 설명용 보드를 실제 플레이 스크린샷으로 소개하지 않습니다.
- 첫 방문 안내를 10개 게임의 첫 조작·첫 목표 비교와 두 가지 플레이 상황으로 개정했습니다.
- 브라우저 게임 글의 포괄적인 역사·성능 주장을 제거하고, 실제 구현에 따른 소리·로컬 기록·파일 캐시·미완료 게임판의 차이를 설명했습니다. 외부 사실에는 Adobe와 MDN의 공식 자료를 연결했습니다.
- 일반 팁에 남은 PatternPop 순서 표현과 SortStack 묶음 이동 표현을 고쳤습니다. PipeLink의 존재하지 않는 Undo 안내와 실제 자동 풀이 힌트 설명도 본문·FAQ·5개 언어에 맞췄습니다.
- 블로그 목록, 게임별 목차, 관련 글과 게임 링크를 정적 HTML로 제공합니다. JavaScript가 없어도 본문과 탐색 링크가 남고, 필터는 JavaScript가 있을 때만 표시됩니다.
- 게시일과 수정일을 구분하고, PuzzleVault 이름의 게시자 표시와 5개 언어의 작성·검토 방법 페이지를 추가했습니다. 실제로 제공되지 않은 운영자 이름, 전문가 자격, 사용자 인터뷰나 플레이 경험은 넣지 않았습니다. 초안·번역·분석의 AI 활용도 설명합니다.
- 글에서 게임으로 이동할 때 언어를 유지합니다. 게임에서 언어를 다시 선택하면 URL도 바뀌며 기존 도전 모드·seed·목표 점수는 보존됩니다.
- 다크 모드의 텍스트 링크 대비와 플레이 버튼의 글자 대비를 수정했습니다. 새 자산 버전과 서비스 워커 캐시는 15입니다.

## 검증

- 전체 Node 테스트: **108개 통과**. 신규 테스트는 실제 게임 함수를 사용해 공개된 예제의 숫자·이동·연쇄 결과를 확인하며, 정적 링크와 언어 경로도 확인합니다.
- 정적 사이트 검사: 공개 HTML **120개**, 차단 항목 **0**, 경고 **0**. 문구 검사의 3개 표시는 모두 보장하지 않는다는 문장을 감지한 것이며 원문을 직접 확인했습니다.
- 브라우저 검사: 320·390·1280px에서 한국어 공략 10개에 페이지 가로 넘침이 없습니다. 그림과 정답 펼치기, 15개 글의 필터, 10개 게임별 바로가기, 5개 언어의 목록과 게임 이동을 확인했습니다.
- JavaScript를 끈 경우에도 목록 15개, 본문, 그림, 관련 글 링크를 사용할 수 있습니다.
- 브라우저 콘솔 오류와 예상하지 않은 외부 자산·추적 요청은 없었습니다. 로컬 검사는 공개 배포·Google 크롤러 접근·실광고 SDK 검증을 대신하지 않습니다.
- 상세 브라우저 결과: `blog-browser-checks.json`. 정적 결과: `site-audit-results.json`.

## 유지관리

원고는 `scripts/content/`에 있습니다. 기존 일반 글, 기존 공략, 새 공략, 첫 방문 안내, 브라우저 게임 설명을 각각 유지합니다. 검토 후 `python scripts/refresh-blog.py`를 실행하면 75개 게시물, 5개 목록, 5개 작성 방법 페이지와 레지스트리·게임 링크·사이트맵이 갱신됩니다. 운영 서버에서는 빌드나 Node/Python이 필요하지 않습니다. 원 게시일은 보존하고 실질적인 수정이 있을 때 수정 날짜를 변경하세요.

검사 명령:

```text
node --test tests/*.test.js
python scripts/audit-site.py
python -m http.server 8765 --bind 127.0.0.1
node scripts/check-blog-browser.cjs <playwright-module-path> http://127.0.0.1:8765 <screenshots-directory>
```

## 공개 반영과 재심사

이 변경은 저장소의 배포 가능한 파일을 개선한 것입니다. Cloudflare Pages 공개 배포와 AdSense 재검토 요청은 별도 단계입니다. 공개 사이트에 수정본이 반영됐는지 확인한 뒤 소유권 확인 상태와 공개 접근을 확인하고, 실제 수정 완료 후 재검토를 요청해야 합니다. 글 개수나 테스트 통과를 승인 보장 조건으로 제시하지 않습니다.

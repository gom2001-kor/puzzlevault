# 메인 게임 그래픽·플레이 확장 — 2026-09-27

이번 변경은 Mosslight Wardens(이끼빛 수호대)와 Cloudweft Passage(구름결 여정)의 장면, 캐릭터, 조작과 진행을 확장한다. 기존 10개 퍼즐의 규칙은 바꾸지 않는다.

## 달라진 플레이

- **이끼빛 수호대:** 세 번의 명중을 연결하는 강화 공격, 충전형 개화 필살기, 돌진·원거리 투사체·내려찍기로 구분되는 적, 선택형 성소 축복, 보스의 두 번째 전투 단계. 정원과 회피, 공격 타이밍을 함께 활용한다.
- **구름결 여정:** 공중 돌진, 점프 버튼을 유지하는 활공, 비행 자원을 회복하는 바람 구슬, 해·달 상태를 맞춰 직접 밝히는 룬. 세 챕터의 경로와 분위기를 구분하고 선택적 유물 탐험을 유지한다.
- 두 게임 모두 기존 저장 형식과 날짜를 지정한 일일 도전 링크를 지원한다. 새 조작과 공략은 영어·한국어·일본어·중국어·스페인어에 반영했다.

## 달라진 화면

공유 WebGL 렌더러에 둥근 모델, 모서리가 다듬어진 지형, 그림자, 하늘 조명, 안개, 발광과 화면 가장자리 보정을 추가했다. 같은 모양의 불투명 모델은 묶어서 그리며 해상도 상한을 둔다. 필요한 GPU 기능이 없으면 인스턴싱 또는 그림자를 생략하는 경로를 사용한다.

숲에는 층이 있는 땅과 바위, 나무 군락, 버섯, 풀, 등불과 배낭을 멘 수호자를 배치했다. 하늘에는 입체 구름, 다리 난간, 폐허의 아치, 관측소, 섬의 지층과 활공 장비를 가진 배달부를 배치했다. 홈의 두 대표 게임 표지도 새로 구성했다. 모델과 표지는 프로젝트의 코드와 SVG로 제작했으며 외부 게임의 캐릭터나 모델을 추가하지 않았다.

## 확인한 범위

- 전체 Node 테스트 **152개 통과**. 세 챕터 완주와 미러 경로, 새 전투·비행·룬 규칙, 저장 복원, 결과 중복 기록 방지를 포함한다.
- Headless Edge에서 두 게임 × 5개 언어, 320/390/1280px 화면, 키보드·포인터 조작, 일시정지, WebGL 복원, 잘못된 저장 데이터, 날짜별 도전, 버전 17 캐시의 오프라인 시작을 확인했다. 브라우저 오류와 외부 요청은 없었다.
- 모바일 멀티터치로 이동 중 활공·돌진을 확인했다. 화면 캡처는 데스크톱과 모바일에서 직접 검토했다.
- 렌더러의 인스턴싱 사용 여부에 따른 픽셀 일치, 자체 그림자 얼룩, 크기 변경 시 GPU 자원 정리, 컨텍스트 복원을 검사했다. 이전 깊이 패킹을 주입하면 그림자 회귀 검사가 실패하는 것도 확인했다.
- 사이트 정적 검사: HTML 122개, 게임 12개, 차단 항목 0개, 경고 0개. 기존 안내 글의 보장을 부정하는 문장 3개는 키워드 검사의 수동 검토 대상으로 유지된다.

결과: [게임 브라우저 검사](flagship-browser-checks.json), [렌더러 검사](premium-renderer-checks.json), [홈 검사](premium-home-checks.json). 세부 규칙은 [숲 게임 설계](mosslight-design.md), [하늘 게임 설계](cloudweft-design.md)에 기록했다.

실제 휴대전화 GPU 전반의 성능을 측정한 결과는 아니다. 오래된 기기의 정밀도 지원 여부는 브라우저에서 기능 응답을 모사해 확인하며 실제 구형 기기 검사와 구분한다. 광고 승인·수익·바이럴 성과를 검증한 변경도 아니다.

## 배포와 캐시

새 스크립트와 이전 HTML이 섞이지 않도록 공개 페이지의 자원 쿼리와 서비스 워커를 버전 17로 함께 올렸다. 다수의 기존 페이지 변경은 이 캐시 버전 갱신이다. Cloudflare Pages Direct Upload 배포는 별도이며 Git 푸시만으로 공개 사이트가 갱신되었다고 간주하지 않는다.

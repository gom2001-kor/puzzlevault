# Little by Little · Reading Room

한국어 사용자를 위한 영어 읽기·듣기·말하기·쓰기 학습 웹앱입니다. 기존 `C:\dev\study-english` 앱의 음성 재생·녹음·복습 경험을 바탕으로, **별도 폴더 `C:\dev\study-english2`에 새로 제작**했습니다. 기존 앱의 코드와 저장 기록은 변경하지 않습니다.

## 바로 실행

```powershell
cd C:\dev\study-english2
npm install
npm run dev
```

기본 주소: **http://127.0.0.1:5174/**. 기존 앱의 5173과 구분됩니다. 포트가 사용 중이면 다른 포트로 조용히 바꾸지 않고 오류를 알려 줍니다.

| 명령 | 기능 |
| --- | --- |
| `npm run dev` | 개발 미리보기, 127.0.0.1:5174 |
| `npm run build` | TypeScript 검사와 `dist` 배포 파일 생성 |
| `npm run preview` | 완성 빌드 미리보기, 127.0.0.1:4174 |
| `npm test` | 콘텐츠·복습·백업 검증 |
| `npm run deploy` | Cloudflare Workers 배포 |
| `npm run deploy:pages` | Cloudflare Pages 배포 |

현재 로컬 구현과 배포용 빌드를 완료했습니다. 웹사이트의 공개 배포는 Git 커밋·푸시와 별도이며, Workers/Pages 설정과 절차는 [배포 안내](docs/DEPLOYMENT.md)를 참고하세요. Node.js 24 권장, React 19 + TypeScript + Vite를 사용합니다.

## 어떻게 학습하나요?

1. **오늘의 학습**에서 처음 또는 이어 읽을 이야기를 엽니다. 임의의 학습 실적을 넣지 않고 실제 학습 기록만 표시합니다.
2. **읽고 이해하기**에서 제목의 ‘제목 뜻·구문’을 열거나 한 구간씩 영어를 읽습니다. **끊어 읽기 / 구문 분석 / 쉬운 문법 / 단어 뜻 / 직접 연습**으로 뜻과 구조를 확인합니다. 영어 단어를 누르면 문맥 뜻·품사·기본형·설명을 보고 발음을 듣거나 복습장에 저장할 수 있습니다. ‘이 문장 익혔어요’를 누르면 다음 구간으로 넘어가고 다음 날 복습 일정이 생깁니다.
3. **표현 익히기**에서 뜻·직접 만든 예문과 발음을 확인하고 책갈피로 저장합니다. 저장한 카드 중 복습 일정이 없으면 오늘 복습 대상으로 추가합니다.
4. **이해 확인**에서 3문항을 풀고 정답과 근거를 확인합니다. 최고 점수를 저장하며 다시 풀 수 있습니다.
5. **내 문장 쓰기**에서 원문에서 배운 표현을 사용해 자신의 생각을 적습니다. 자동 저장과 작성문 듣기를 지원합니다. 자유 글쓰기에 AI 점수나 자동 교정 결과를 꾸며 붙이지 않습니다.
6. **스피킹 스튜디오**에서 문장을 듣고 최대 60초 동안 따라 말해 녹음하거나, 원문을 가리고 받아쓰기를 합니다. 학습실에서 선택한 구간을 바로 스튜디오로 보낼 수 있습니다.
7. **기억하는 복습**에서 먼저 답을 떠올리고 확인한 뒤 기억 정도를 선택합니다. ‘다시 볼게요’는 오늘 대기열 뒤로, ‘기억했어요’는 이전 간격의 2배(최소 2일·최대 60일), ‘아주 쉬워요’는 3배(최소 3일·최대 90일)로 예약합니다. 새로 완료한 문장의 최초 복습은 다음 날입니다.

긴 작품의 소요 시간은 **선정한 핵심 구간 학습** 기준입니다. 원문 전체를 공부한 것과 구분합니다. 같은 수업의 ‘전체 원문’에서는 검증한 범위의 영어 본문 전체를 읽을 수 있습니다. 의미 단위로 나눈 구간도 있으므로 69개 구간이 모두 독립된 완전한 문장인 것은 아닙니다. 난이도는 편집상 추정이며 공인 CEFR 등급이 아닙니다.

**자세한 분석은 8개 제목과 69개 선정 학습 구간 전체에 적용됩니다.** 전체 원문의 모든 문장을 분석한 것은 아닙니다. 전체 원문에서 색이 표시된 구간을 누르면 해당 구간 분석으로 이동합니다. 제목·대사·문장 일부를 구별해 설명하고, 주어·동사 등이 없는 표현에 억지로 문장 틀을 적용하지 않습니다.

끊어 읽기는 의미 덩어리별 역할과 우리말 뜻을 보여 주며 뜻 가리기, 개별 듣기, 연속 듣기, 속도·쉼·반복 조절을 지원합니다. 직접 연습에서는 덩어리 순서 조립과 짧은 회상 문제를 풉니다. 같은 구간에서 문법이나 단어 탭을 참고한 뒤 돌아와도 조립 상태와 답안이 유지됩니다. 구간을 바꾸거나 페이지를 나가면 이 임시 연습 상태는 초기화됩니다. 회상 답안은 예시와 비교하며 자유 답안을 AI로 채점하지 않습니다.

## 음성·녹음

문장·단어·예문은 Web Speech API의 **기기 합성 음성**으로 읽습니다. 원 출처의 녹음이나 원어민 녹음 파일을 가져온 것이 아닙니다. 설정에서 미국/영국 영어, 사용 가능한 목소리, 0.5–1.25배속을 고릅니다. 재생 중 같은 스피커나 ‘음성 중지’를 누르면 멈춥니다. 페이지를 이동할 때도 중지합니다.

끊어서 듣기는 0.5 / 0.9 / 1.5초의 덩어리 사이 쉼과 1–3회 반복을 제공합니다. 재생 중 덩어리를 강조하며 쉼 중에도 중지할 수 있습니다. 속도·반복·쉼을 바꾸거나 구간·분석 탭을 이동하면 예약된 다음 재생도 취소합니다. 대사의 알려진 화자 표시는 끊어 듣기에서 제외하되 화면 원문에는 보존합니다.

영어 음성이 없는 브라우저에서는 설정 안내를 표시합니다. Chrome·Edge·Safari의 지원과 설치된 음성에 따라 품질이 다르고, 일부 음성은 인터넷을 사용합니다. 앱의 테스트 브라우저에는 영어 음성이 없어 **실제 음질은 검증하지 못했습니다**.

녹음은 사용자가 ‘녹음 시작’을 누를 때만 마이크 허용을 요청합니다. 앱 서버로 전송하지 않고 화면 메모리에만 보관합니다. 문장/모드/화면 변경 또는 새로고침으로 사라집니다. 백업에는 포함하지 않습니다. 마이크는 HTTPS 또는 localhost 같은 보안 환경에서 지원됩니다. 개발 중 실제 마이크 권한을 허용하거나 사용자 음성을 녹음하지 않았습니다. 발음 자동 평가와 음성 인식은 제공하지 않습니다.

받아쓰기는 원문의 구두점·대소문자·공백 차이를 정규화해 비교합니다. 자유 답안을 평가하는 AI 채점은 아닙니다. 대화문에 표시된 화자 이름도 원문과 함께 비교합니다.

## 저장과 백업

학습 진도, 저장한 카드, 복습 일정, 퀴즈 최고 점수, 쓴 글, 목표·음성 설정은 `localStorage`의 `little-by-little.reading-room.v2`에 저장합니다. 기존 앱의 `little-by-little.v1`과 분리되어 있습니다. 같은 브라우저라도 도메인·포트·프로필이 달라지면 기록도 다릅니다. 계정·자동 동기화·서버 저장은 없습니다.

이번 학습 해설 확장은 기존 v2 문장·표현 카드 ID와 저장 형식을 유지합니다. 제목과 문맥별 단어를 새 카드로 저장할 수 있으며, 복습장의 원문 링크로 해당 제목 또는 구간에 돌아갈 수 있습니다. 새 단어 카드가 추가되었다고 자동으로 복습 대상이나 완료 진도를 늘리지는 않습니다.

설정의 ‘전체 기록 백업’으로 JSON을 저장하고 ‘백업 불러오기’로 검사합니다. 복원 미리보기 뒤 ‘이 백업으로 복원’을 눌러야 현재 기록을 교체합니다. 5MB 이하의 이 앱 전용 백업만 받습니다. 기존 앱의 v1 백업은 서로 다른 콘텐츠 구조라 바로 가져오지 않습니다.

손상된 저장 데이터를 읽으면 기존 값을 보존하고 자동 저장을 멈춥니다. 정상 백업을 복원해 재개할 수 있습니다. 저장 공간 부족 시 화면에 오류를 표시하며 현재 메모리의 기록을 백업할 수 있습니다.

How to Play QuickCalc

Choose the correct answer, or use keys 1–4. Consecutive correct answers build a combo for more points. Classic and Daily give you 3 hearts and a timer for each question. The daily course changes at midnight UTC and can be replayed for practice. Timed modes subtract 3 seconds for each wrong answer. Frequently Asked Questions

What modes are available?

Classic: three lives and a timer per question. Daily: the shared daily course, replayable. Time Attack: two minutes, with a three-second penalty per wrong answer. Duel: a shared 30-second course without hints or extra time.

How does scoring work?

Correct answers earn 100 × phase, plus remaining seconds ×10 and consecutive correct answers ×50. Operator questions double the answer’s points.

What is Operator Roulette?

From question 11, some questions hide one operator, such as 7 ? 3 = 21. Choose × to solve it. Correct operator answers earn double points. Outside duels, a hint can narrow the choices to two.

How are answer choices made?

Numeric choices mix the correct value with nearby and more distant errors, then shuffle their positions. Duel friends receive the same choices in the same positions.

# PuzzleVault 게임 업그레이드

## 구현한 플레이 흐름

홈의 간단한 몸풀기 퀴즈 → 30초 QuickCalc 대결 → 콤보와 개인 기록 → 같은 문제의 친구 도전 링크/이미지 카드 → 일일 미션·경험치 → 다른 퍼즐 탐색으로 이어집니다.

- 홈: 모바일 대응, 게임 취향 필터, 마지막 게임 이어가기, 5개 언어 지원.
- 성장: 10종 게임의 완료 기록에 경험치 지급. 하루 3판, 서로 다른 2종, 그날의 추천 게임을 완료하는 세 가지 미션. 레벨·4종 배지·UTC 기준 연속 플레이 기록. 로그인 없이 해당 브라우저에 저장.
- 대결: 30초 동안 같은 seed의 문제와 선택지를 제공. 오답은 3초 차감. 대결 중 힌트·시간 추가 금지. 재도전은 같은 코스, 새 도전은 새 코스. 친구 점수는 검증되지 않은 친선 기록이며 공개 순위처럼 표현하지 않음.
- 공유: 실제 플레이 가능한 코스 링크와 PNG 기록 카드. 공유창 취소를 공유 성공이나 자동 복사로 처리하지 않음.
- 안정성: 반복 완료·재시작 타이머·NumVault 애니메이션 중 중복 입력 방어. 배포 버전이 포함된 자산과 오프라인 도전 링크 지원.

## 수익 연결 상태

기존 AdSense 태그는 유지했습니다. 임시 전면 광고, 가짜 보상 완료 메시지, 광고 DOM 삭제/자동 갱신을 제거했습니다. 보상형·전면 광고 공급자는 아직 연결하지 않았습니다. 미연결 상태에서 도움 기능은 무료입니다. 실제 공급자 설정, 테스트 광고, 노출·완료·매출 확인은 [광고 연결 준비 문서](monetization-readiness.md)를 따릅니다.

바이럴과 수익은 출시 후의 실제 이용자 행동으로 판단해야 합니다. 첫 게임 완료율, 두 번째 게임 진입률, 다음날 재방문, 성공 공유, 도전 링크 유입 후 완료를 먼저 살펴보고 광고 매출과 함께 비교하세요. 가상의 이용자 수·순위·예상 매출은 넣지 않았습니다.

## 확인 방법

저장소에서 `python -m http.server 4173 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:4173/ko/`를 여세요. 테스트는 `node --test tests/*.test.js`로 실행합니다. 별도 설치나 빌드 과정이 없습니다.

실제 브라우저에서 모바일 390px 홈·필터·몸풀기, 30초 대결 완료·XP 저장·같은 문제 재도전을 확인했습니다. 자동 테스트는 코스 재현성, 잘못된 URL, 타이머, 보상 중복, UTC 전환, 저장소 오류, 공유 취소, 광고 완료/취소/시간 초과, 다국어와 자산 연결, 오프라인 URL을 검증합니다.

변경은 로컬 소스에 반영되었으며 운영 사이트 배포와 실제 광고 계정 설정은 수행하지 않았습니다.

# 콘텐츠·신뢰·문의 화면 점검

점검일: 2026-09-28(KST). 이전 AdSense 화면의 사유는 **가치가 별로 없는 콘텐츠**였습니다. 아래는 사이트 소스와 실제 브라우저에서 확인한 사항입니다. Google 계정의 심사 상태나 승인을 확인한 문서는 아닙니다. 광고 활성화 절차는 [운영 가이드](adsense-operations-2026-09-28.md)를 참고하세요.

## 기준과 판단

- Google의 AdSense 준비 안내는 독창적이고 유용한 내용, 읽기 쉽고 동작하는 탐색 구조를 강조합니다. 원문을 가져올 때에는 자체 해설 등 이용자에게 추가 가치를 제공해야 합니다. 정해진 글 수를 채우거나 의미 없는 분량을 늘리는 작업으로 해석하지 않았습니다. [페이지 준비 안내](https://support.google.com/adsense/answer/7299563?hl=en)
- 게시자 정책은 가치가 낮거나 본문이 없는 화면, 별도 해설·선별·부가 가치 없는 복제 콘텐츠, 권리 침해 및 불명확한 개인정보 처리를 다룹니다. 정책 페이지를 추가했다는 사실만으로 실제 콘텐츠와 광고 배치의 적합성을 대신할 수 없습니다. [Google 게시자 정책](https://support.google.com/publisherpolicies/answer/10502938?hl=en)
- Google 검색의 AI 안내는 유용성과 품질을 중심으로 설명합니다. 이것은 검색 안내이며 AdSense의 자동 승인 조건이 아닙니다. AI 활용 사실을 감추거나 존재하지 않는 전문가·경험을 만드는 대신, 기존 편집정책의 AI 보조·검토 범위 공개를 유지했습니다. [Google 검색의 AI 콘텐츠 안내](https://developers.google.com/search/blog/2023/02/google-search-and-ai-content), [사람을 위한 콘텐츠](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)

## 발견하고 수정한 내용

| 발견 | 조치 |
| --- | --- |
| 영어 학습실이 추가됐지만 소개와 약관은 게임만 설명 | 5개 언어의 소개·약관에 실제 학습 기능, 한국어 UI와 영어 원문, 별도 XP, 비공인 학습 기록, 자료별 권리 범위를 반영 |
| 통합 앱의 공개 콘텐츠 업데이트 요청이 개인정보 안내에 없음 | 원본 `study-english2.pages.dev` 요청 시 호스팅 제공자가 IP 등 일반 요청 정보를 받을 수 있음, 답안·녹음·진도는 이 요청에 보내지 않음, 자료 수신과 기록 이전의 차이를 5개 언어에 명시 |
| 문의 내용이 게임 오류 중심 | 자료 제목·구간·문제 번호·근거로 학습 내용을 정정하는 방법, 권리 문제 제보 시 필요한 최소 정보 안내 |
| 소개·약관에서 학습 출처와 자체 해설에 도달하기 어려움 | 정적 읽기 가이드, 앱 출처 화면, 현지 언어 편집정책으로 직접 연결 |
| 문의 버튼 글자색이 일반 링크 규칙에 덮여 배경과 같아짐 | 문의 및 지원 페이지의 기본 버튼 색을 명시. 흰 글자·진한 파랑 배경의 대비 6.7:1, 44px 이상 클릭 영역 |
| 어두운 모드의 정책 링크가 어두운 파랑으로 표시 | 밝은 파랑으로 변경하고 실제 카드 배경에 대한 대비 검사 |
| 지원 페이지의 메타 설명이 본문 첫 단락 전체를 복사 | 각 페이지 용도에 맞는 간결한 설명으로 교체 |
| 편집정책에 새 영어 자료의 작성·갱신 범위가 없음 | 원문과 자체 학습 해설을 구분하고 형식 검사가 내용·전세계 권리 검증을 뜻하지 않음을 설명. 정적 가이드의 배포본과 앱 최신 자료의 차이 안내 |

`scripts/content/support-learning.json`과 `scripts/refresh-editorial.py`에서 20개 지원 페이지를 유지합니다. 편집정책은 `scripts/content/editorial.json`에 원고를 보관하며, `scripts/refresh-blog.py`가 정책별 수정일을 사용합니다. 변경하지 않은 기존 공략들의 날짜를 새 날짜로 덮어쓰지 않았습니다.

## 원문 권리 확인 범위

VOA의 공식 안내는 VOA가 단독 제작한 자료와 제3자 권리 자료를 구분합니다. 매체 이름만으로 그 페이지의 모든 자료를 자유 이용 자료로 간주할 수 없습니다. [VOA 이용 조건](https://learningenglish.voanews.com/p/6021.html)

Project Gutenberg는 미국 외 지역의 권리 상태를 보장하지 않는다고 설명합니다. 기존 학습 자료의 미국·한국 확인 범위가 모든 국가의 상업 이용 권리 검토를 뜻하지는 않습니다. 출처 표기나 공개영역 표시만으로 이런 차이가 없어지지 않습니다. 영어 학습 앱의 광고가 비활성인 현재 상태를 유지하고, 자료 추가·변경 시 본문과 이용 조건을 함께 검토해야 합니다. [Project Gutenberg 이용 조건](https://www.gutenberg.org/policy/license.html)

## 검증 결과와 한계

- 실제 Edge: 5개 언어 × 밝은/어두운 모드 × 320/390/1280px = 30개 문의 화면에서 기본·호버 버튼 및 지원 링크 대비 4.5:1 이상, 클릭 높이 44px 이상, 가로 넘침 없음. 보고서: [support-browser-checks.json](support-browser-checks.json).
- JavaScript를 끈 상태에서 5개 언어의 영어 학습 소개, 정적 가이드 링크, 자료 권리 약관, 업데이트 수신 개인정보 안내 확인.
- 해당 브라우저 검사에서 실행 오류 0, 자동 외부 요청 0. 이 결과는 지원 페이지 범위이며, 공개 자료를 가져오는 학습 앱 전체의 외부 요청이 0이라는 뜻은 아닙니다.
- 기존 공략 연결·언어·구조 데이터 검사 2개 통과. Python 템플릿 컴파일 통과.
- 기존 문의 링크 `https://forms.gle/NBjCNdVCBGaGGcbM9`는 Google Forms로 이동하여 HTTP 200, 제목 `PuzzleVault Contact`를 반환했습니다. 문의를 실제 제출하지 않았으므로 운영자의 수신·처리 여부까지 확인하지 않았습니다.
- 사용자가 요청한 대로 PuzzleVault라는 이름과 기존 문의 경로를 유지했습니다. 운영자 이름, 이메일, 자격, 수신 기록이나 처리 기한을 만들어 넣지 않았습니다.

심사 재요청 전에는 개선본을 공개 주소에 배포하고 문의 양식의 실제 수신을 운영자 계정에서 확인해야 합니다. 코드·콘텐츠 개선은 승인이나 광고 수익을 보장하지 않습니다.

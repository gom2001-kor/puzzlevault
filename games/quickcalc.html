How to Play QuickCalc ⚡

Choose the correct answer, or use keys 1–4. Consecutive correct answers build a combo for more points. Classic and Daily give you 3 hearts and a timer for each question. The daily course changes at midnight UTC and can be replayed for practice. Timed modes subtract 3 seconds for each wrong answer. A 30-second duel uses the same question sequence and answer positions for both friends, with no hints or extra time. Share your result to send that exact course to a friend. Challenge scores are self-reported and are not a verified leaderboard.

Frequently Asked Questions

What are the different game modes?

Classic: 3 lives, increasing difficulty. Wrong answers cost a life. Daily: A shared daily sequence, replayable for practice. Time Attack: 2 minutes, answer as many as possible, wrong = -3s penalty. 30s duel: Challenge a friend on the same course, without hints or extra time.

How does the scoring work?

Each correct answer earns 100 × phase (1-4) points, plus a speed bonus (remaining seconds × 10) and a streak bonus (consecutive correct × 50). Operator Roulette answers earn ×2 points!

What is Operator Roulette?

From question 11, sometimes the operator is hidden: "7 ? 3 = 21" — you must identify "×". Correct operator answers earn double points. Outside duels, hints can narrow the choices to 2.

Are the wrong answers generated randomly?

No! There's one near miss (±1-3), one medium miss (±5-15), and one far miss. Careful!
